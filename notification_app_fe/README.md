# Campus Notification System — Frontend

A Next.js frontend that displays campus notifications (placements, results, events) with a Priority Inbox.

## Features
- Filter notifications by type: All, Placement, Result, Event
- Priority Inbox — ranks notifications by type weight and recency
- Logs all user actions to the evaluation service
